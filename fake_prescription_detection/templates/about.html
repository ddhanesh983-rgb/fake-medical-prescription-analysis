B.Sc. Data Science Capstone Project

Fake Medical Prescription Detection Using Machine Learning & Python

A multi-layered technological approach designed to empower pharmacists and healthcare institutions with automated screening tools to counter prescription fraud and illicit drug diversion.

Problem Statement & Existing Limitations

Prescription fraud contributes significantly to the opioid epidemic, medication diversion, and pharmacy liability. Traditional verification suffers from severe bottlenecks:

Manual Phone Verification

Dispensaries often face busy clinics or delayed callbacks, forcing rushed triage during peak hours.

Visual Forgery Sophistication

Desktop publishing tools allow bad actors to replicate letterheads, medical logos, and physician stamps.

Human Fatigue

Subtle anomalies like slightly future dates, altered dosage units, or fabricated registration numbers escape manual review.

Proposed System Architecture

Computer Vision (OpenCV)

Applies adaptive histogram equalization (CLAHE) and bilateral filtering to normalize document illumination and enhance degraded text contrast.

Optical Character Recognition (Tesseract)

Transcribes visual typography into machine-readable unicode text with spatial bounding coordination.

Rule-Based Clinical Auditor

Validates state/national doctor registration IDs, patient demographics, chronological validity, and flags Schedule II controlled substances.

Machine Learning Model (Scikit-Learn)

Extracts TF-IDF n-gram vectors and computes class probabilities using Logistic Regression / Random Forest classifiers.

Machine Learning Methodology & Evaluation

The machine-learning pipeline enforces strict data separation between training and test sets to eliminate data leakage. The model is evaluated through standard statistical metrics:

Metric Clinical Formula Screening Significance
Precision TP / (TP + FP) Minimizes false alarms that unduly inconvenience legitimate patients.
Recall (Sensitivity) TP / (TP + FN) Crucial for catching fraudulent documents before illicit dispensing.
F1-Score 2 * (P * R) / (P + R) Harmonic balance between precision and recall across imbalanced data.

Future Enhancements & Ethical Guardrails

Future work focuses on integrating live API lookups with National Medical Councils, electronic prescription signature validation, and federated learning across hospital networks.

Responsible AI Protocol: Automated systems must never render final punitive decisions. All suspicious classifications trigger human-in-the-loop review by licensed medical practitioners.
